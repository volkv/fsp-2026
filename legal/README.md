# Правовые документы платформы

Тексты согласий и соглашений, которые видит человек на пути регистрации и в настройках (`docs/domain.md`, раздел 6.2).
Один файл — один вид документа из `src/lib/server/consent/kinds.ts`; свойства каждого вида (заголовок, цели, категории
данных, действия, требуется ли повторное согласие) и оператор персональных данных — в `documents.json`.

Все тексты — **редакции прототипа**: оператор персональных данных не определён, его реквизиты в `documents.json` —
явные заглушки. Перед реальным запуском тексты и реквизиты заменяет юрист оператора.

Публикует `scripts/seed-legal.ts` (`pnpm db:seed-legal`, а в контейнере — при каждом старте): для вида, у которого текст,
заголовок или свойства изменились, выходит новая версия, прежняя помечается вытесненной; без изменений повтор ничего не
меняет. Опубликованная версия неизменяема (триггер базы), поэтому правка текста — это всегда новая версия.
