# Компонентная схема

- Компоненты и их ответственность: веб-приложение (интерфейс и API), фоновые обработчики, PostgreSQL с pgvector, хранилище ключ-значение, файловое хранилище S3, сервис разбора документов, песочница исполнения кода, модели, почта, шлюз.
- Связи между компонентами: протоколы, направления вызовов, что синхронно и что через очередь заданий.
- Внешние системы: ФСП ID (OIDC), реестр ФСП, ЕГРЮЛ, Telegram, ATS работодателей.
- Изоляция: сеть, права контейнеров, закрытый контур моделей.
- Отказоустойчивость: упрощённый режим без моделей и при недоступности сервисов.
- Схема компонентов (диаграмма).
