# Сборка, развёртывание и локальный запуск

- Требования к машине: ОС, Docker и Compose, память и диск; модели — отдельно.
- Пошаговый локальный запуск одной командой и проверка, что всё поднялось.
- Наполнение демонстрационными данными и учётные записи для проверки.
- Развёртывание на сервере: `docker-compose.prod.yml`, переменные окружения, домен и TLS, резервные копии.
- Подключение моделей: закрытый контур, порядок запуска, работа без моделей.
- Сборка из исходников и проверки качества кода.
- Сборка этой документации.
