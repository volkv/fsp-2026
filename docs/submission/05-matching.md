# Механика подбора и категоризация

- Логика категоризации кандидата по стеку, специализации, грейду и пройденным тестам; объяснение категории кандидату и возражение.
- Учёт достижений ФСП и корректная работа с кандидатом без истории ФСП.
- Поиск работодателем: фильтры по категории, ранжирование, скор соответствия вакансии и его компоненты.
- Объяснимость выдачи: почему кандидат в подборке и на каком месте.
- Выход на контакт: приглашение с вилкой зарплаты и версиями условий, ответ кандидата, раскрытие контактов.
- Классический отклик кандидата на вакансию как дополнительный сценарий.
