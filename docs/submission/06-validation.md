# Процедура валидации и результаты

- Данные для оценки: синтетические резюме и вакансии с независимой разметкой, как они построены.
- Метрики подбора: доля релевантных кандидатов в топе выдачи на наборе пар «вакансия — кандидат».
- Метрики тестирования: согласованность грейда при повторном прохождении, дискриминативность заданий, соответствие эталонной разметке.
- Метрики разбора резюме и категоризации.
- Как воспроизвести оценку: команда запуска, пороги, отчёт.
- Результаты и их ограничения.
