# Описание API

- Принципы: версия `/api/v1`, документ OpenAPI 3.1 из схем маршрутов, интерактивная документация `/api/docs`.
- Аутентификация: сессия браузера с CSRF-токеном, ключ API компании и его права.
- Ошибки: единый конверт, коды и статусы HTTP.
- Пагинация, идемпотентность, лимиты запросов.
- Вебхуки внешних систем и их подписи.
- Перечень операций (ниже, сформирован из документа OpenAPI).
