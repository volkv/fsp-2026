Школа программирования выгружает оценки из электронного журнала. Нужна ведомость: средний балл каждого ученика и общий средний балл.

## Вход

В первой строке — число `N` (1 ≤ N ≤ 100 000). Далее `N` строк вида

```
ИМЯ;ПРЕДМЕТ;ОЦЕНКА
```

- `ИМЯ` — непустая строка до 60 символов, может содержать пробелы и буквы любого алфавита, но не `;`;
- `ПРЕДМЕТ` — непустая строка до 60 символов без `;`;
- `ОЦЕНКА` — целое от 2 до 5.

Имена сравниваются точно, с учётом регистра и пробелов: `Анна` и `анна` — разные ученики.

## Выход

Для каждого ученика — строка

```
ИМЯ: СРЕДНИЙ (КОЛИЧЕСТВО)
```

в порядке убывания точного среднего балла; при равенстве — по возрастанию имени в порядке `String.compareTo`. Последняя строка — `total: СРЕДНИЙ (КОЛИЧЕСТВО)` по всем оценкам.

Средний балл выводится с двумя знаками после точки, округление — **половина вверх от точного значения** (`3.665` → `3.67`, `3.664` → `3.66`). Сравнивать при сортировке нужно точные значения, а не округлённые.

## Пример

Вход:

```
6
Иванова Анна;Алгоритмы;5
Петров Пётр;Алгоритмы;4
Иванова Анна;Базы данных;4
Петров Пётр;Базы данных;5
Сидоров Иван;Алгоритмы;3
Иванова Анна;Сети;4
```

Выход:

```
Петров Пётр: 4.50 (2)
Иванова Анна: 4.33 (3)
Сидоров Иван: 3.00 (1)
total: 4.17 (6)
```
